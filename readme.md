# 🎓 ClubTU

> แพลตฟอร์มศูนย์กลางสำหรับค้นหา สมัคร และจัดการกิจกรรมชมรมภายในมหาวิทยาลัย

ClubTU ช่วยให้นักศึกษาสามารถ **ค้นหาชมรมที่สนใจ ดูกิจกรรม สมัครเข้าชมรม และติดตามข่าวสาร** ได้ในที่เดียว พร้อมช่วยให้ชมรมจัดการสมาชิก กิจกรรม และประกาศต่าง ๆ ได้ง่ายขึ้น

## 💡 Problem

ข้อมูลชมรมและกิจกรรมภายในมหาวิทยาลัยมักกระจายอยู่ตามหลายช่องทาง เช่น Facebook, Instagram, LINE หรือ Google Forms ทำให้นักศึกษาค้นหาข้อมูลได้ยาก และอาจพลาดช่วงเวลารับสมัครหรือกิจกรรมสำคัญ

## ✨ Solution

ClubTU รวบรวมข้อมูล **ชมรม กิจกรรม และข่าวสาร** ไว้ในแพลตฟอร์มเดียว ทำให้นักศึกษาค้นหาและเข้าร่วมกิจกรรมที่สนใจได้สะดวกมากขึ้น

## 🎯 Target Users

* 👨‍🎓 นักศึกษาใหม่ที่ต้องการค้นหาชมรม
* 🎓 นักศึกษาที่ต้องการเข้าร่วมกิจกรรม
* 🏢 สมาชิกและผู้ดูแลชมรมที่ต้องการจัดการชมรม

## 🚀 Key Features

* 🔎 ค้นหาและค้นพบชมรมตามความสนใจ
* 📅 ดูและสมัครเข้าร่วมกิจกรรม
* 📝 สมัครเข้าชมรม
* 🔔 ติดตามข่าวสารและกิจกรรม
* 👥 จัดการสมาชิกและกิจกรรมสำหรับชมรม
