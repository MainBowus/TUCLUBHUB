# TUCLUBHUB
 
แพลตฟอร์มค้นหา สมัคร และจัดการชมรมของมหาวิทยาลัยธรรมศาสตร์

## หน้าจัดการชมรม

เปิดหน้า `club-admin/club-admin.html` ด้วยบัญชี Firebase Auth ของผู้ดูแลชมรม โดยเอกสารในคอลเลกชัน `clubs` ต้องมีฟิลด์ `adminUid` เป็น UID ของบัญชีนั้น เช่น:

```text
clubs/{clubId}
	name: "ชื่อชมรม"
	adminUid: "firebase-auth-uid"
```

ก่อนสร้างชมรมครั้งแรก ให้สร้างเอกสาร `clubAdmins/{firebase-auth-uid}` ใน Firestore เพื่อให้ระบบรู้ว่าบัญชีนี้เป็นแอดมิน แม้ยังไม่มีชมรม เช่นใส่ `email` และ `active: true` ได้ จากนั้นแอดมินจะกด “เพิ่มชมรม” และระบบจะใส่ `adminUid` ให้เอง

หน้าดังกล่าวจะอ่านใบสมัครจาก `applications` ที่มี `clubId` ตรงกับชมรมของแอดมิน และเขียนผลกลับไปยังเอกสารเดิมด้วย `status` (`pending`, `approved`, `rejected`), `reviewedAt` และ `reviewedBy` ซึ่ง Dashboard นักศึกษานำไปแสดงผลต่อได้

ตอนล็อกอิน ระบบจะตรวจ UID ของ Firebase Auth กับ `clubs.adminUid` อัตโนมัติ ถ้าพบชมรมที่ตรงกันจะพาไปหน้าแอดมินชมรม ถ้าไม่พบจะพาไป Dashboard นักศึกษา ดังนั้นไม่ต้องกำหนดอีเมลแอดมินในโค้ด

การใช้งานจริงควรตั้ง Firestore Rules ให้ตรวจ `request.auth.uid == resource.data.adminUid` สำหรับข้อมูลชมรม และตรวจว่า `applications.clubId` เป็นชมรมที่ผู้ใช้เป็นแอดมินก่อนอนุญาตให้อ่านหรืออัปเดตสถานะ อย่าใช้การซ่อนปุ่มฝั่งหน้าเว็บเป็นมาตรการควบคุมสิทธิ์เพียงอย่างเดียว
